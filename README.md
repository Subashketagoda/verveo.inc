## 🚀 Agency Features

- **Cinematic Hero**: Architectural visual frame with 4K RAW cinema playback, dynamic interactive light orbs, and a 4-showcase switcher.
- **The Verveo Disciplines**: Editorial split-screen showcase with sticky preview viewport and inline mobile accordion.
- **Interactive Capability Spectrum**: Six core studio pillars with hover states and mobile-friendly expanders.
- **Archival Selected Work**: Filterable portfolio archive featuring deep-dive modal case studies and full static case study routes (`/projects/[slug]`).
- **Client Guardianship Carousel**: 6-part editorial series with touch swipe gesture navigation and fullscreen lightbox.
- **Live Transmissions (Instagram)**: Real synced feed components, story highlight bubbles, and pinned typographic marble installations.
- **Mobile First**: 100% responsive across iPhones, Android devices, tablets, and high-DPI displays. No horizontal overflow drift and zero iOS Safari input auto-zooming.
- **3.0s Minimal Luxury Preloader**: Elegant VE® monogram reveal with micro-progress sequence.

## 🛠 Tech Stack

- **Framework**: [Next.js 16 App Router](https://nextjs.org/) (Turbopack)
- **Styling**: Vanilla CSS & Tailwind CSS v4 design system
- **Typography**: Syne, Space Grotesk, Plus Jakarta Sans
- **Icons**: Lucide React + Bespoke Brand Monograms
- **Animations & Effects**: Canvas Confetti, CSS Keyframe Glows, Smooth Transitions

## 🏁 Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm start
```
